# Architecture Decision Records (ADRs)

This directory maintains the sequenced Architectural Decision Records for the **Smart_Schedular (JU CSE Academic Management System)** project.

## What is an ADR?

An Architectural Decision Record (ADR) captures an important architectural decision made along with its context, options evaluated, and consequences.

## Creating New ADRs

To create a new ADR, copy [`template.md`](file:///docs/adr/template.md) and number it sequentially (e.g. `0004-feature-name.md`).
